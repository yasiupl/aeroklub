# Surowe źródła

Ten katalog zawiera pliki źródłowe: artykuły, pliki PDF, skany, zdjęcia i notatki z rozmów.

- Dodaj plik do tego katalogu. Nazwa pliku: `RRRR-MM-DD-krotki-opis.rozszerzenie`.
- Nie zmieniaj i nie usuwaj plików w tym katalogu. Wiki opiera się na nich.
- Agent czyta nowe pliki i dodaje je do wiki (operacja „ingest” w `CLAUDE.md`).
- Notatka z rozmowy: plik `.md` z datą, uczestnikami i faktami. Nie zapisuj prywatnych numerów telefonów ani adresów.
